## 📌 Featured Projects

### 🎀 [KiraKira yt-dlp Studio](https://github.com/TheGNM/KiraKira-Studio)

A PySide6 desktop interface for managing yt-dlp downloads through a persistent, sequential queue. Supports video, audio, subtitles, thumbnails, configurable output settings, queue backups, per-job logs, and a draggable Lilac desktop companion.

**Built with:** Python, PySide6, yt-dlp, and FFmpeg.

### 🤖 [Yume — AI Companion](https://github.com/TheGNM/open-waifu)

A locally run AI companion with a custom personality, persistent long-term memory, and a web chat interface.

**Built with:** Ollama, ChromaDB, FastAPI, and a custom web UI.
